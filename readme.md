# Weather Web App

A simple and responsive weather app built using HTML, CSS, and vanilla JavaScript. It connects to an open-source weather API to show real-time weather details for any city you search.

## Features

* **City Search:** Get live weather conditions for cities globally.
* **Dynamic Icons:** Automatically switches between day and night SVG icons based on the time.
* **Weather Codes:** Translates numeric API codes into readable text like "Clear Sky" or "Overcast".
* **Responsive Layout:** Works smoothly on mobile, tablet, and desktop screens.

## Project Structure

```text
├── assets/        # SVG icons for day and night weather conditions
├── index.html     # Page layout
├── style.css      # Custom styling
├── script.js      # Fetching API data and updating the UI
└── readme.md      # Project documentation
```

## How to Run It

1. Click the green **Code** button at the top of this GitHub page and select **Download ZIP**.
2. Extract the downloaded ZIP file on your computer.
3. Open the folder and double-click the `index.html` file to run the app directly in your web browser. No installation or setup needed.
